# Template Engine Examples

Examples for `@lib/template_engine` focused on room-facing text rendering.

## Files

- `01_numeric_and_named.ts`
  - welcome and tip-menu text via numeric and named placeholders
- `02_nested_conditionals_defaults.ts`
  - limitcam status rendering, fallback defaults, and missing-key behavior
- `03_recursive_rendering.ts`
  - recursive rendering and message-body styling output
